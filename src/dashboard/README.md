# Yoga Session Builder
This project was originally created from react mui [example projects](https://github.com/mui/material-ui/tree/master/examples)

## Usage
The Sesh Builder and the pose database go hand in hand.  You can select a pose from the list of available poses, or you can add you own pose to the pose database. Although this project uses yoga as a starting point, the intent is to be able to use SeshBuilder for any type of movement, be it tai chi, weight lifting, etc.
